## Receiving effect and selected realization

L-J01–L-J06 need one reusable transformation between a bounded command, its stable slot/content identities, and an exactly verifiable journal record. Preserve the existing artifact identity, typed witness construction and EAVT row laws. Extend their existing pure `journal/event.mjs` module with the three functions below; do not introduce an application codec, serializer, store, queue, provider adapter or new package. These are Code/Data laws with no filesystem, networking, clock or credential effects. They make no authority or storage decision. The existing module is admitted as placement of witness laws, not as design authority for their behavior.

The ordinary journal exports retain witness identities, core/observation values, verified source bodies and admission behavior; F-U07 removes locale dependence from source ordering and preserves historical permutations. Existing parseJournalWitness remains available with the source-set compatibility refinement in F-U07; the new record verifier applies its own exact correspondence rather than weakening the new contract to fit old permissiveness. Nothing in this order enables the journal's unique-admission API or grants dispatch permission. L-J07–L-J09 and effect-domain validation remain independent necessary integrations.

## Exported functions

**F-U01 — Address a command.** Add `addressUniqueJournalCommand(value, journalIdentity)`. It returns exactly `{command,commandRef,slotDigest}`, a deeply frozen JSON snapshot: `command` is an admitted copy of the caller value, commandRef uses addressArtifact, and slotDigest uses L-J02's exact tuple. Every identifier, closed object, domain/key correspondence, reference syntax, reference order, JSON resource bound and predecessor-in-causes condition in L-J01 is enforced. The journalIdentity argument is a nonempty string of at most 512 Unicode scalar values, rejecting unpaired surrogates. It is supplied by the trusted service caller; this function cannot prove that a deployment admits it. Effect-key journal must equal it. There is no parsing of paths or normalization of identifiers.

`value` inside the command is generic bounded JSON here; the domain validator is responsible for its interpretation. In particular, `value.approved = true`, a model-generated role or a syntactically valid grant reference confers no authority. This pure function neither invokes a validator callback nor claims to have checked a grant.

**F-U02 — Build a retained record.** Add `uniqueJournalRecord(command, options)`. Options is a closed object containing exactly `journal`, `seat`, `admittedAt`, and `artifacts`, all required. Journal and seat obey the identifier bound. admittedAt is a real timestamp whose round trip through the existing JavaScript date representation equals the original 24-character UTC-millisecond text; reject alternative offsets, normalized invalid dates and extended years. The interaction seat must equal command.key.principal. Use F-U01 to admit the command and compute its identity.

Construct the exact observation with fields `kind`, `seat`, `claim`, `address`, `time`, `causes`, `payload`, and `referencedArtifacts`, including the last array even when empty. Its kind is metroplat.journal.observation; payload is `[command.subject,"metroplat.journal.unique-admission",command,admittedAt]`; claim is `tm.mark("metroplat.journal.unique-admission")`; address is `tm.mark(eavtKey(payload))`; causes and referencedArtifacts are the command arrays. Use journalWitness, with F-U07's source ordering, for the existing witness construction; do not reimplement its six source artifacts, articulation, core identity or boundary record.

Options.artifacts is the L-J05 external artifact array in strictly increasing ordinal reference order, with exactly the required external set after subtracting verified witness-source references. Do not silently sort, deduplicate or ignore supplied entries. Each entry is closed `{ref,canonicalText}`; canonicalText must equal the canonical text returned by verifyArtifact for that reference. Additional, repeated, missing, noncanonical or mismatched bodies refuse.

Return exactly the L-J05 envelope `{kind,version,journal,commandRef,witness,artifacts}`, deeply frozen and independent of caller-owned mutable objects. Apply the specified JSON resource envelope to the whole constructed retained record as well as its parts. Do not return file bytes, an admission disposition, durability receipt or created flag. This is construction of an unpersisted value.

**F-U03 — Verify a retained record.** Add `parseUniqueJournalRecord(value, journalIdentity, expectedSlotDigest)`. All three arguments are required. expectedSlotDigest is exactly 64 lowercase hexadecimal characters supplied by the source locator. Apply bounded JSON admission before copying/hashing. The record must have exactly L-J05's six envelope fields, correct literals and configured journal, and no inherited or extra semantic properties admitted by the JSON contract.

Recover the command only from the witness observation's four-element EAVT payload. Verify expected subject, attribute and time correspondence by reconstructing the entire record through F-U02 from that command, record journal, observation seat/time and artifacts. Compare canonical JSON of the supplied record to canonical JSON of that reconstruction. This exact comparison rejects additional witness/observation fields, altered claim/address, fabricated core/sources, mismatched original time, altered reference arrays, omitted empty referencedArtifacts, or changed commandRef. Calling parseJournalWitness alone is insufficient. The exact reconstructed slot digest must equal expectedSlotDigest.

Return exactly `{record,command,slotDigest,reference}` as a deeply frozen snapshot, with reference exactly `{journal,subject,event,payload}` from L-J06. event is the verified original witness ID, payload the commandRef, and subject the original command subject. Different observation times for identical commands produce the same commandRef and slotDigest but normally different witness IDs; the persistence boundary must select the first record and return that original reference. This parser must not choose a winner or infer which call created it.

**F-U07 — Source order is representation, not authority.** Change journalWitness's source-array sort from localeCompare to ordinal reference comparison (the valid references are ASCII, so ordinary code-unit order suffices). This must not change any artifact's canonical body/reference, witness core, witness ID, boundary observation, causes, or the existing handling of optional observation fields. Only the array representation order changes.

Refine parseJournalWitness to compare its supplied source array as an exact set of reference/body pairs against the newly reconstructed expected array. Require an array of exactly the expected length, each entry with exactly ref and canonicalText, each reference occurring once, and every pair matching the reconstructed reference/body. Reject extra entry fields, wrong types, duplicate references, missing or surplus sources, changed canonical text and invented identities. Do not silently discard duplicates or accept merely content-equivalent noncanonical source text. Keep its existing checks of witness kind, ID, bytes, core and reconstructed observation. Return the reconstructed witness in canonical ordinal source order. Older ordinary witnesses in another source-array order remain readable without rewriting retained source files or readdressing the witness.

New unique-record parsing remains stricter than historical ordinary witness parsing: F-U03's whole-record reconstruction requires the canonical source order inside a version-1 unique record. Historical compatibility of ordinary source arrays is not permission to silently normalize a noncanonical new unique record. The record source and its exact canonical bytes remain independently verifiable.

## Existing-law observation and review limits

A [controlled observation](evidence/2026-09-27-journal-unique-wire/observation.json) used the current artifact, EAVT and journal-witness functions on one fixture command at two dates. Command content identity and slot identity remained stable; observation witness identities differed; each witness round-tripped through the current parser. The explicitly supplied empty observation referencedArtifacts array survived, while the core retained its own boundary artifact. This falsified a review concern that journalWitness would remove that explicit empty field. It does not exercise the future three exports or the domain message schema.

The source-order change addresses the dependency on locale-sensitive comparison visible in the existing constructor and exact-source-array comparison visible in the parser. No cross-locale production failure was observed here. Its acceptance requires the independent F-U06 observations, including historical source permutations; neither this diagnostic nor a reviewer assertion supplies that acceptance.
