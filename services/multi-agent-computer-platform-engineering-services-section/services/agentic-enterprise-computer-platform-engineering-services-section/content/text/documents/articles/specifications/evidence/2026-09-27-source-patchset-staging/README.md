The disposable exercise demonstrated one batch creating a file, editing a unique substring, omitting a retired file and retaining an unchanged executable file, with original source bytes and modes unchanged. Nineteen invalid-input cases refused without successful new receipts or source mutation. The captured result predates this archival copy; no additional run is claimed.

Invoke the tool with Python 3 and three arguments: the inventory JSON, candidate JSON, and absolute fresh stage path. It performs no model call, candidate execution, deployment or shared-checkout promotion. Candidate source remains governed by the isolated generation contract. The observation program is preserved verbatim, including its original temporary-path assumptions; the captured observation is not a portable rerun command.

Scope: local disposable staging only. This is not journal, domain authorization, assistant, multi-file atomic promotion, or hostile filesystem-race acceptance.
