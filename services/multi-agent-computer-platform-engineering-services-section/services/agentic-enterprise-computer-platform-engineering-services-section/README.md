# Agentic Enterprise Computer Platform Engineering Services Section

This section specializes multi-agent computer platform engineering to
platforms whose persistent operating environment is an agentic enterprise.
Such platforms host enterprise claims, work, capabilities, providers,
settlements, and governed effects without locating the enterprise's
intelligence or authority in any one model invocation.

## Apps

- `apps/metroplat` — MetroPlat, the schema-driven agentic-enterprise operation
  host that derives CLI, HTTP, MCP, and LSP surfaces from one witnessed catalog
  of certified relational operations.
