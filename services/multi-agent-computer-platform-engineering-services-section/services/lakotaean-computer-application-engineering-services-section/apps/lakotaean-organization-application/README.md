# @emsenn/organizing-as-lakota

A library of **lakotaean becoming** — metaphysics, kinship, lifeway, governance — presented as the Lakota fiber over the `relating → animating → organizing` web.

This package is carried under the captain's vested authority as a Lakota person.
It articulates the Lakota tradition on its own terms; the formal substrate does work *for* the tradition, it does not constitute or authorize it.
The tradition's authority is held by Lakota knowledge holders in living tradition, not by being formalizable.

## The substantive claim

The four superior Wakȟáŋ — **Škáŋ, Wí, Makȟá, Íŋyaŋ** — *are* the four values of the relational field's bilattice.
Not four beings plus four logic-values: the four logic positions in cosmogonic form.
The Western algebra (Belnap's FOUR, `@emsenn/relating`'s charge) is a re-presentation of what the cosmogony already names.
Lakota cosmology is the **source-form** of the bilattice, not the reverse.

So this library does not posit its metaphysics — it **derives** it from the substrate it fibers.
Where the corpus records a cosmogonic relation, the package checks it against the charge algebra and carries the algebra's verdict.

## The tree is the proof

The source descends the Lakota becoming spine, each segment generated by the one before, mirroring the corpus's own earned path (`content/_archive/existence/lakota/`).
The spine morphisms are named in Lakota (ASCII slugs in paths; full orthography ȟ/š/ŋ in the code), and each concept is its own file at its earned coordinate:

```
src/iyokheya/                          iyókheya — articulating/discharging (to set apart)
  tobtob-kin/tobtob-kin.mts            tóbtób kiŋ: the four superior Wakȟáŋ = the four charges
  iyan-hanhepi.mts  wakhan.mts  heyokha.mts  mitakuye-oyasin.mts
  wotakuye/                            wótakuye — predicating (kin-relating)
    takuye.mts  iyuha-sni.mts  yuhapi.mts  hunkapi.mts
    wolakota/                          wólakȟota — positing (the way)
      wolakota.mts                     the discipline 𝒮_wolak + standing-as-wólakȟota
      wowacantognaka.mts woksape.mts woohitika.mts wowacintanka.mts   the four virtues
      inikagapi.mts hanblecheyapi.mts wanagi-yuhapi.mts …             the seven rites
      wicozani/                        wičhózani — settling (coming-to-wholeness)
        wicozani.mts  oyate.mts  ocethi.mts
        naca.mts  akicita.mts  zuya.mts  omniciye.mts  recognition.mts
```

`iyokheya` (set-apart) / `wotakuye` (kin-relating) / `wolakota` (the way) / `wicozani` (coming-to-wholeness) are the Lakota names for the articulating/predicating/positing/ settling descent; `ocethi` (Očhéthi, the council fire) houses the governance signature.

## Built so far — the becoming spine (46 tests green)

**Metaphysical core** (`tobtob-kin.mts`) - **Tóbtób Kiŋ** — the four superior Wakȟáŋ named over the four charges (`Škáŋ`=⊥/absurd, `Wí`=t/absurd, `Makȟá`=f/active, `Íŋyaŋ`=⊤/stable), with the `wakanOfCharge` / `chargeOfWakan` bijection. - **`discharge()`** — the cosmogony as the internal structure of the four-charge field, each recorded relation *checked by the charge algebra*: `Wí ∨ₖ Makȟá = Íŋyaŋ`, `Wí ∧ₖ Makȟá = Škáŋ`, `∼Wí = Makȟá`, `Škáŋ`/`Íŋyaŋ` self-dual. - **`markWakhan` / `wakanTanka`** — wakȟáŋ as a cell-and-rule quality, Wakȟáŋ Tȟáŋka as its global pattern (the sacred *is* the structure of relation — not a God-entity). - **`mitakuyeOyasin()`** — the global kinship-cosmos theorem.
