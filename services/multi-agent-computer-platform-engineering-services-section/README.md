# Multi-Agent Computer Platform Engineering Services Section

This section specializes multi-agent computer system engineering to whole
platforms: inhabitable operating environments constituted across multiple
agents, composing the faculty apps owned by the upstream agent and
multi-agent sections into persistent, programmable world runtimes.

Specialized platform kinds continue under `services/`.

## Apps

- `apps/feltos` — FeltOS, the Felt Operating System: a deterministic,
  event-sourced world kernel and MUD engine. Moved here 2026-08-26 from
  `computer-mud-engineering-services-section/apps/fizzos` (its pre-rename
  name); that section retains the generic MUD engine/mudlib lineage
  custody and MUD engineering scope.

## Service specializations

- `services/agentic-enterprise-computer-platform-engineering-services-section/`
  owns platforms whose persistent operating environment is an agentic
  enterprise. Its first app is MetroPlat.
